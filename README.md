# Greenfetch

Ferramenta CLI utilizada para ler input de utilização de Bateria e calcular custos de carbono do sistema operacional/hardware

Projeto desenvolvido como parte dos requisitos da matéria "Atividade Extensionista" para a graduação em Análise e Desenvolvimento de Sistemas da UNINTER.

# Instalação 

Requisitos:
* Sistemas Operacional Linux
* Go 1.25.12
* Clone do repositório

Uma vez dentro do diretório clonado desse repositório, basta só rodar:

```sh
go build -o greenfetch main.go
```
e após executar com:

```sh
./greenfetch
```
